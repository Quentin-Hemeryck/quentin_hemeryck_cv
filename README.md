# CV Web – Projet Front-End  

## Description  
CV en ligne réalisé dans le cadre du cours de **Développement Front-End 2024-2025**.  
Site **one-page** en **HTML, CSS et JavaScript (jQuery)** présentant mon parcours, mes compétences et mes expériences de manière professionnelle et responsive.  

## Fonctionnalités  
- Responsive design (320px → 2560px)  
- Accessibilité (alt, contraste, texte redimensionnable)  
- Référencement optimisé (balises sémantiques, métadonnées)  
- Effet d’animation avec le plugin **Particles.js**  
- Bouton pour **imprimer le CV** (CSS print optimisé)  

## Technologies  
- HTML5  
- CSS3  
- JavaScript (ES6 + jQuery)
